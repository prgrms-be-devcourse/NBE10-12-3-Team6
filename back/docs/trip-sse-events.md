## **📄 작업 요청 내용**

Post 도메인을 제외한 Kotlin 여행 도메인의 변경 사항을 여행방 단위 SSE로 전달한다.

- 사용자가 여행방에 입장한 뒤 하나의 공통 SSE 연결을 유지할 수 있도록 한다.
- 여행방의 모든 화면에서 같은 방식으로 변경 알림을 표시한다.
- 화면을 나갔다 다시 들어오기 전까지 조회 결과가 갱신되지 않는 화면에는 동기화 UI를 제공한다.
- 본인이 수행한 작업은 본인에게 알리지 않고, 다른 참여자에게만 알린다.
- 시스템이 수행한 작업은 여행방 참여자 모두에게 알린다.

  - 여행방 개요의 동기화 아이콘은 다른 사용자가 여행방에 새로 참여한 `TRIP_MEMBER_JOINED` 이벤트에만 활성화

## **📍 기타**

- Post 도메인은 아직 Kotlin 마이그레이션 대상이 아니므로 수정하거나 이벤트를 연결하지 않았다.
- 여행방 하위 화면은 공통 SSE 연결과 공통 상단 알림 애니메이션을 공유한다.
- Post 조회에 의존하는 사진 기록 및 전체 타임라인 화면은 이번 동기화 버튼 적용 대상에서 제외했다.
- 기존 타임라인 프론트가 바로 깨지지 않도록 기존 SSE 구독 API와 이벤트 이름을 유지했다.
- 전체 백엔드 테스트는 62개 중 61개가 성공했다. 실패 1개는 기존 `TripGroupV1ControllerTest`의 필수 요청 필드 누락 테스트로, 예상 상태 400과 실제 상태 500이 다른 문제이며 이번 SSE 변경과 직접 관련이 없다.
- 프로젝트 전체 `pnpm lint`는 기존 화면들에 남아 있는 React Hooks/JSX 정적 검사 오류 때문에 통과하지 않으며, 이번 작업의 신규 공통 알림 컴포넌트는 개별 ESLint 검사에서 오류가 없다.
